**Find hidden pad identifiers in the PDF text layer.** Open the original board PDF in a text-search-capable PDF viewer and go to page 1. Use Find for the full Altium pad identifier: PAP101 is P1 pin 1, PAP1030 is P1 pin 30, PAP201 is P2 pin 1 and PAP301 is P3 pin 1. These identifiers are hidden PDF text, not visibly printed pad numbers; a search highlight locates the pad. Select the exact token (or use whole-word search), because PAP101 can also match the prefix of PAP1010. The identifiers follow PA + header ID + 0 + pin number. Do not identify pin 1 from pad shape alone: P2 pin 44 (PAP2044) and P3 pin 4 (PAP304) are also square, in addition to each header's pin 1. **Read the offset rear legends using their matching white dots.** Three rear header rows have their legends printed farther inboard. A white dot beside each row matches a white dot at the end of a short line above its offset legend. Condition: Normal SystemClock_Config startup [HAL_PWREx_EnableUSBVoltageDetector](https://github.com/Gugic/fanadapter/blob/8c48cfe422bae50b96b04b9c8de813d434e0bd54/firmware-stm32/src/main.c#L164-L165) [USB pins without hardware VBUS sensing](https://github.com/Gugic/fanadapter/blob/8c48cfe422bae50b96b04b9c8de813d434e0bd54/firmware-stm32/src/main.c#L177-L184)
- **SYSRESETREQ and system-memory bootloader handoff:** Both reboot and dfu request NVIC_SystemReset (SYSRESETREQ/SFTRESET). The dfu path first disconnects TinyUSB and writes a DTCM token; the early token check then branches to ROM. The application does not drive NRST or BOOT0 via GPIO. RM0433 §8.4.2, Figure 43 documents the internal reset generator and its specified minimum pulse; that controller effect is distinct from the measured external waveform.
