### Non-GPIO firmware roles

- **Internal LDO / VCORE supply:** HAL_PWREx_ConfigSupply(PWR_LDO_SUPPLY), VOS1, and a bounded VOSRDY wait configure the internal regulator; these are power-system roles rather than user GPIO assignments. Board VCAP/power/ground connections belong in the physical wiring model. Condition: Normal SystemClock_Config startup [SystemClock_Config supply/VOS](https://github.com/Gugic/fanadapter/blob/8c48cfe422bae50b96b04b9c8de813d434e0bd54/firmware-stm32/src/main.c#L116-L128)
- **VDD33USB voltage detector:** HAL_PWREx_EnableUSBVoltageDetector enables the USB transceiver supply-rail detector. This is not assignment of PA9 to USB VBUS sensing, and is not a programmable external USB 5 V switch. Condition: Normal SystemClock_Config startup [HAL_PWREx_EnableUSBVoltageDetector](https://github.com/Gugic/fanadapter/blob/8c48cfe422bae50b96b04b9c8de813d434e0bd54/firmware-stm32/src/main.c#L164-L165) [USB pins without hardware VBUS sensing](https://github.com/Gugic/fanadapter/blob/8c48cfe422bae50b96b04b9c8de813d434e0bd54/firmware-stm32/src/main.c#L177-L184)
- **SYSRESETREQ and system-memory bootloader handoff:** NVIC_SystemReset requests an internal system reset; dfu first disconnects TinyUSB, writes a DTCM token and resets. A token then branches to ROM at the first statement of main. The application does not drive NRST or BOOT0 via GPIO. ROM code has its own pin configuration, outside this source audit. Software DFU-entry reliability remains separately unresolved. Condition: reboot / dfu commands; DTCM token checked before all application peripheral initialization [check_bootloader_request / request_bootloader_reboot](https://github.com/Gugic/fanadapter/blob/8c48cfe422bae50b96b04b9c8de813d434e0bd54/firmware-stm32/src/main.c#L529-L567) [console command reset paths](https://github.com/Gugic/fanadapter/blob/8c48cfe422bae50b96b04b9c8de813d434e0bd54/firmware-stm32/src/main.c#L583-L590) [main early ROM check](https://github.com/Gugic/fanadapter/blob/8c48cfe422bae50b96b04b9c8de813d434e0bd54/firmware-stm32/src/main.c#L693-L699) [cmd_reboot / cmd_dfu](https://github.com/Gugic/fanadapter/blob/8c48cfe422bae50b96b04b9c8de813d434e0bd54/firmware-stm32/src/protocol.c#L390-L406)
